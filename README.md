# 拾词 · 四六级单词本

一个白色主题、手机优先的静态 H5 单词本。不需要安装、不需要后端，词库和复习进度都保存在浏览器本地。

- 拍照 / 截屏 / 粘贴文本识别英文单词（浏览器端 OCR）
- 联网查询音标、英文释义、例句和中文翻译
- 看词选义、例句填空、句中辨义三种练习
- 按艾宾浩斯遗忘曲线自动安排下一次复习
- 支持词条编辑、词组搭配、发音、数据导入导出
- 可选接入任意 OpenAI 兼容接口，做 OCR 文本纠错与更干净的识词

## 怎么打开

### 方式一：直接双击（最快，但拍照受限）

双击 `index.html`，用 Chrome、Edge、Safari 或 Firefox 打开即可。

大多数功能可以离线使用。只有“联网查词”需要访问 dictionaryapi.dev 和 MyMemory。

拍照 OCR 的引擎和英文语言包已经放在 `tess/` 目录里，**不需要联网下载**；但浏览器会限制 `file://` 页面加载 OCR Worker，所以直接双击时拍照识别不可用，页面会提示改用方式二。

### 方式二：本地起一个静态服务（推荐，拍照可用）

在 `shici-wordbook` 文件夹里打开终端，任选一种：

```bash
# 有 Python
python -m http.server 8080

# 有 Node.js
npx serve .

# 有 PHP
php -S localhost:8080
```

然后浏览器打开：

```text
http://localhost:8080
```

手机访问：手机和电脑连同一个 Wi-Fi，手机浏览器输入 `http://电脑的局域网IP:8080/`（启动窗口会打印这个地址）。不要输入 `localhost` 或 `127.0.0.1`，那会指向手机自己；如果打不开，检查 Windows 防火墙是否放行 8080。

### 方式三：部署成真正的链接

整个 `shici-wordbook` 文件夹是纯静态文件，可以直接拖到下面任一平台，拿到一个可分享的 HTTPS 链接：

- GitHub Pages
- Netlify Drop
- Vercel
- Cloudflare Pages

不需要构建命令，发布目录就是 `shici-wordbook` 本身。

> 部署后请用 HTTPS。浏览器在非安全上下文中可能限制语音、Worker 等能力。

## 第一次使用

1. 首次打开会自带 **内置四六级词库（约 200 个词，含手写单词表整理的 152 个）**，其中 6 个已经到期，可以直接点「开始今日复习」体验。
2. 想用自己的词：进入「拍照」，上传单词书/试卷照片，或把文本粘贴到「手动输入」。
3. 勾选识别出的词，点「加入词库」。查不到中文释义的词会标记为「待补充」，可以在词条里点「联网补全」或手动编辑。
4. 进入练习后，每题作答会立即显示释义、例句、词组和下次复习时间。
5. 在「我的」里可以设置每日目标、词库等级、自动发音、AI 增强，以及导出备份。

## 三种练习

| 题型 | 考什么 | 选项 |
| --- | --- | --- |
| 看词选义 | 单词 → 中文释义 | 中文 |
| 例句填空 | 把单词填回四六级难度例句 | 英文单词 |
| 句中辨义 | 读句子，判断句中单词的含义 | 中文 |

练习默认混合出题。答对会展示这个词下一次出现的时间；答错会立刻安排更早复习，并可在本轮结束后「重练错词」。

### 全库闯关

词库页有一张「全库闯关」卡片，不受每日目标限制：

- 词库里所有有释义的词随机出现；
- **第一次作答就答对，这个词直接过**；第一次答错，则要之后再**连续答对 3 次**才算过，中途答错就清零重来；
- 同一个词答完后会插回队列后方，不会紧接着再次出现；
- 只剩最后一个词时，会插入一个已过词做「穿插复习」，这题不计入闯关；
- 顶部显示「已过 X / 总词数」，全部词过掉后结束；
- 中途退出不会丢复习记录，但这一轮没有过掉的词下次需要重新开始计数。

它和「开始今日复习」是两条线：今日复习仍按每日目标抽 10 个左右的到期/新词；全库闯关是整库集中过一遍。

## 艾宾浩斯复习规则

复习间隔共 9 档：

```text
5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天
```

- 新词从第 1 档开始。
- 答对：按当前档位安排下次复习，然后前进一档。
- 答错：退回两档，并按退回后的间隔安排复习。
- 每次到期时间会加 ±6% 的随机浮动，避免所有词挤在同一分钟。
- 只有「有释义」的词会进入练习；待补充释义的词不会浪费复习机会。

这套规则是简化版艾宾浩斯调度，不是严格的 SuperMemo/FSRS 算法；它的目标是让错词更早回来、熟词逐步拉长间隔。

## 数据存在哪里

全部数据保存在当前浏览器的 `localStorage`：

- 键名：`shici.state.v1`
- 内容包括：词条、释义、例句、词组、复习阶段、到期时间、答题历史、每日统计、设置
- 换浏览器、换设备、清理站点数据后不会自动同步
- 「我的 → 导出备份」会下载一个 JSON 文件；换设备时用「导入备份」恢复
- 导出时会清空 API Key，避免把密钥写进备份文件；换设备后需要重新填写
- 导入会覆盖当前词库，导入前会二次确认
- API Key 只保存在本机 `localStorage`，不会上传到本项目以外的服务器

## 联网与隐私

### 查词

- 英文音标、词性、英文释义、例句：`dictionaryapi.dev`
- 单词中文直译、例句中文翻译：`MyMemory`
- 发音：优先使用有道词典的公开发音音频；失败时退回浏览器 `speechSynthesis`
- 查询结果会在本地缓存 7 天，减少重复请求

### OCR

- OCR 使用 `Tesseract.js 5.1.1`，引擎、Worker、WASM 核心和 `eng` 语言包都在 `tess/` 目录里，识别时**不联网**
- 图片只在浏览器内处理，不会上传到服务器
- 必须通过 HTTP 打开（`启动单词本.bat`、本地静态服务或线上部署）；`file://` 会提示改用本地服务
- 更适合印刷体、截屏、扫描件；**手写体识别率有限**，手写单词表建议用下面的「云端增强」，或直接用「手动输入」粘贴
- 识别失败时不会编造单词，会提示检查 `tess/` 是否完整、是否用了本地服务

### 云端增强 OCR（可选）

本地 Tesseract 对手写体几乎不可用。拍照结果页提供「云端增强」按钮，把当前图片上传到 `ocr.space` 再做一次识别：

- 默认使用 `ocr.space` 的公开试用 Key `helloworld`，可能限流或排队；如果页面提示 `HTTP 429`，就在「我的 → 云端增强识别」里填自己的免费 Key（ocr.space 注册后即可获得）
- 只有点「云端增强」并确认后，图片才会上传；不上传时仍走本地 OCR
- 手写体实测能读出大部分单词，但会有拼写错误（例如 `deep-seated` 读成 `acep-seated`），加入词库前请逐词勾选、改错
- 图片只用于这一次识别，不会保存在本项目；介意上传就继续用本地 OCR 或手动输入

### 可选 AI 识词增强

在「我的 → AI 识词增强」里可以填写任意 OpenAI 兼容接口：

- Base URL，例如 `https://api.deepseek.com`
- 模型名，例如 `deepseek-chat`
- API Key

启用后会在两个环节帮忙：

1. **识别后校对**：配置好 AI 后，本地或云端识别完成都会自动跑一次；也可以手动点结果页的「AI 校对」。它会纠正 OCR 拼写、删掉 `word/list` 这类页眉噪声，并补全缺的音标和中文释义。加入词库前还会再核对一次词条。
2. **收录前核对**：点「加入词库」时，先把选中的词批量交给 AI 校对，再用词典接口查词条；AI 只补词典缺失的字段，不会覆盖已有的词典释义。这样拼错的词会先改对，再入库。

只发送 **候选词或 OCR 文本**，不发送图片。AI 也会出错，加入前请看一眼词条；不开 AI 时仍可用词典查询，只是少了拼写纠正和缺字段补全。

> 这是浏览器直连第三方接口，是否能连通取决于对方是否允许跨域（CORS）。如果「测试连接」失败，先确认 Base URL、模型名和 Key，再查看服务商是否允许浏览器调用；AI 增强失败不影响 OCR、查词和复习。

## 已知限制

1. **这不是完整四六级词库。** 内置约 200 个词（48 个手工示例 + 152 个手写单词表整理词）用于起步；拍照识别和联网查词负责继续扩充自己的词库。在线接口不保证每个词都有中文释义或四六级真题例句。
2. **有道的 JSON 词典接口没有开放 CORS**，静态页面不能直接调用它，所以默认没有使用有道词条。若需要更强的四六级真题例句，需要自己加一层允许 CORS 的代理，或在 `js/api.js` 里替换数据源。
3. **OCR 不是万能的。** 手写体、低清晰度、复杂排版、竖排单词书的识别率会明显下降；印刷体本地实测约 1 秒。手写图建议点「云端增强」，识别后逐词勾选、改错，不要直接全量加入。
4. **没有账号和云同步。** 数据只在这台设备的这个浏览器里，请定期导出备份。
5. **已在 Edge 中实测首页、词库、拍照页、设置页的渲染、一轮答题流程，以及本地 OCR 的打印样图识别**；在线查词和不同手机浏览器仍需你按下面清单自测；首次打开请留意控制台报错。

- [ ] 首页能显示今日目标、到期词、内置词库统计

- [ ] 三种题型都能出现：看词选义、例句填空、句中辨义
- [ ] 答对 / 答错后，「下次复习」时间发生变化
- [ ] 词库搜索、筛选、排序、词条详情、编辑、删除都正常
- [ ] 拍照上传后能显示 OCR 进度和候选词；`tess/` 完整时无需联网，`file://` 会提示改用本地服务
- [ ] 手写图点「云端增强」，确认后能返回候选词；介意上传时取消，仍用本地 OCR/手动输入
- [ ] 「手动输入」粘贴文本能提取单词并加入词库
- [ ] 导出 JSON 后，清空词库，再导入能恢复

- [ ] 刷新页面后词库和复习进度仍在

## 文件结构

```text
shici-wordbook/
├── index.html          页面骨架
├── styles.css          白色主题、响应式布局
├── README.md           本文件
├── serve.py            本地静态服务（拍照识别用）
├── tess/               Tesseract 引擎与英文语言包（离线）
├── my-words.json       手写单词表整理出的 152 个词（原始）
├── my-words.enriched.json  补充音标/例句后的数据
└── js/
    ├── data.js         常量、48 个核心示例词
    ├── my-words.js     把 152 个手写词追加到内置词库
    ├── store.js        localStorage、复习调度、统计
    ├── api.js          查词、翻译、OCR、发音、可选 AI
    └── app.js          路由、页面渲染、练习、弹层、事件
```

放到 `D:\桌面\文件夹\单词本` 时，同目录还会多出 `打开单词本.html`、`启动单词本.bat`、`打开单词本.url`、`先看我.txt`。

## 想改成自己的词库

- 改内置示例词：编辑 `js/data.js` 里的 `WB.SEED_WORDS`
- 改复习间隔：编辑 `js/data.js` 里的 `WB.INTERVALS`（单位毫秒）
- 改每日目标：编辑 `WB.DAILY_GOALS`，或在「我的」里切换
- 改查词来源：编辑 `js/api.js` 的 `lookup()`；只要返回结构包含 `term / phonetic / meanings / example / phrases / level`，页面就能直接使用

---

如果只想要一个能马上打开、背单词的版本：双击 `index.html` 即可。拍照 OCR 必须通过本地静态服务或 HTTPS 部署打开。
